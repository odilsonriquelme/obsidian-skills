DESCRIÇÃO
---------
Coleção de Agent Skills para uso com o OBSIDIAN. Seguem a especificação Agent Skills
(agentskills.io), então funcionam em qualquer agente compatível (Claude Code, Codex CLI).
Instaláveis via marketplace de plugins do Claude Code.

AS 5 SKILLS (cada uma com SKILL.md em inglês + EXPLICACAO-PT-BR.md seu)
-----------------------------------------------------------------------
skills/defuddle/         → extrai conteúdo limpo de páginas web (via Defuddle CLI),
                           removendo menus/propaganda; salva só o texto relevante.
                           (PR do upstream: pula .md URLs.)
skills/obsidian-markdown/→ criar/editar Obsidian Flavored Markdown: wikilinks [[ ]],
                           embeds ![[ ]], callouts, frontmatter (propriedades), tags.
                           (Tem references/ com CALLOUTS.md, EMBEDS.md, etc.)
skills/obsidian-bases/   → criar/editar Obsidian Bases (.base): views de banco de dados
                           de notas com filtros, fórmulas e sumários.
skills/obsidian-cli/     → interagir com o vault via CLI (ler, criar, buscar notas) e
                           desenvolver/depurar plugins e temas.
skills/json-canvas/      → criar/editar arquivos JSON Canvas (.canvas): mapas visuais,
                           fluxogramas e diagramas de conexão. (Tem references/EXAMPLES.md.)
